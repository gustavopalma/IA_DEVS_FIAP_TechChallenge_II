# Tech Challenge – Fase 2 | IA para Devs

Projeto desenvolvido para o **Tech Challenge – Fase 2 da Pós Tech IA para Devs – FIAP**.

O Proje inclui implementações de um algoritmo genético para otimização dos hiperparâmetros do Decision Tree Classifier utilizado no modelo de classificação.

O LLM do Google Gemini também foi integrado para uma melhor apresentação dos resultados da classificação. Modelos de escalabilidade e monitoramento também foram incluídos
